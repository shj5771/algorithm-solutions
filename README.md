# algorithm-solutions

프로그래머스 / 백준 문제 풀이 기록.

## 어떻게 돌아가는가

```
프로그래머스에서 문제 통과
   ↓  백준허브 크롬 확장 (자동)
이 레포에 커밋
   ↓  /algo-post (스케줄 or 수동)
drafts/ 에 네이버 블로그용 초안 생성
   ↓  bin/copy-draft.sh
클립보드에 서식 유지 복사 → 스마트에디터에 붙여넣고 발행
```

발행 버튼만 사람이 누른다. 네이버는 2020년 5월 글쓰기 API를 종료했고 약관상
매크로를 제재 대상으로 두기 때문에, 자동화는 초안 생성까지만 한다.

## 디렉터리

| 경로 | 용도 | 누가 쓰는가 |
|---|---|---|
| `프로그래머스/`, `백준/` | 풀이 코드 | 백준허브 (자동) — **손으로 건드리지 않는다** |
| `drafts/` | 블로그 초안 | `/algo-post` |
| `bin/` | 클립보드 복사 헬퍼 | 사람 |

백준허브가 만드는 폴더 구조는 `사이트 - 레벨 - 문제번호.문제명` 이다.
이 규칙에 맞춰 초안 생성기가 새 풀이를 찾는다.

## 사용법

```bash
# 아직 초안이 없는 새 풀이들로 초안 생성
/algo-post

# 특정 초안을 클립보드에 서식 유지 복사
bin/copy-draft.sh drafts/2026-07-28-programmers-42586.html
```

## 초안을 다시 만들고 싶을 때

`drafts/.processed.json` 에서 해당 문제 키를 지우고 `/algo-post` 를 다시 돌린다.
